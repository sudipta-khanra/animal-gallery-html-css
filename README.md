# Animal Gallery Web App

A **mobile-responsive**, desktop-first interactive animal gallery web app built using **HTML5** and **CSS3**.

## Features

- Sidebar menu with smooth CSS transitions
- Gallery with 20 animal cards and hover effects
- Contact and feedback forms with interactive UI
- "Coming Soon" popup boxes for future sections
- Clean, semantic HTML structure with modern CSS animations
- Fully responsive design for desktop, tablet, and mobile

## Technologies Used

- **HTML5**
- **CSS3**
